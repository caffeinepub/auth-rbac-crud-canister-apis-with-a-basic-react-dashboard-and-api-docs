# TaskFlow - Secure Task Management Dashboard

A full-stack task management application built on the Internet Computer with role-based access control and secure authentication.

## Features

- 🔐 Secure authentication via Internet Identity
- 👥 Role-based access control (User/Admin)
- ✅ Complete CRUD operations for tasks
- 🎨 Modern, responsive UI with dark mode support
- 🚀 Built on the Internet Computer for decentralized hosting

## Prerequisites

- [DFX](https://internetcomputer.org/docs/current/developer-docs/setup/install/) (Internet Computer SDK)
- Node.js 18+ and pnpm
